# AI-deck ESP32 firmware for NanoCockpit

This is the NanoCockpit firmware for the ESP32 (NINA module) on the AI-deck. It passes CPX packets
between the GAP8 and a computer over Wi-Fi, and is used together with the
[NanoCockpit applications for the GAP8](https://github.com/bitcraze/aideck-gap8-examples/tree/master/nanocockpit).
It is an alternative to the original [aideck-esp-firmware](https://github.com/bitcraze/aideck-esp-firmware).
